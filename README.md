# AI Interior Designer

AI-консультант по дизайну интерьера на базе LLM.

Проект помогает пользователю:
- определить предпочтения в интерьере
- подобрать стиль
- спроектировать помещение
- согласовать планировку
- выбрать цвета, мебель и освещение
- получить полноценную концепцию ремонта

---

# Возможности

## Интерактивный диалог

AI не просто задаёт шаблонные вопросы.

Он:
- помогает определиться со стилем
- уточняет предпочтения
- предлагает варианты
- согласовывает каждый этап ремонта

---

## Анализ предпочтений

Если пользователь не знает стиль, AI:
- определяет вкусы через диалог
- предлагает подходящие направления
- объясняет различия между стилями

---

## Поэтапное проектирование

Проектирование разбито на этапы:

1. Знакомство с помещением
2. Анализ текущего состояния
3. Определение стиля
4. Планировка
5. Цветовая концепция
6. Мебель
7. Освещение
8. Системы хранения
9. Финальная концепция ремонта

AI не переходит к следующему этапу,
пока пользователь не согласует текущий.

---

## Подробная дизайн-концепция

Вместо сухих советов AI создаёт
развёрнутое описание интерьера.

Пример:

- атмосфера помещения
- визуальные акценты
- материалы
- сочетания цветов
- сценарии освещения
- эргономика
- хранение
- практические рекомендации

# Установка

## 1. Клонировать репозиторий

```bash
git clone https://github.com/gagatun16/LogicModel.git
```

---

## 2. Перейти в папку проекта

```bash
cd LogicModel
```

---

## 3. Создать виртуальное окружение

### Windows

```bash
python -m venv .venv
```

Активировать:

```bash
.venv\Scripts\activate
```

---

## 4. Установить зависимости

```bash
pip install -r requirements.txt
```

---

# Настройка API ключа

Создайте файл:

```text
.env
```

Внутри:

```env
OPENROUTER_API_KEY=your_api_key
```

---

# Запуск

```bash
python main.py
```
